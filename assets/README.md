# assets/

Общие ассеты курса. Проекты могут иметь собственные каталоги `assets/` внутри
себя; этот каталог — общий для примеров и заданий.

```
assets/
├── fonts/      ← шрифты (.ttf, .otf)
├── textures/   ← текстуры и спрайт-листы (.png, .jpg)
├── sounds/     ← звуковые эффекты (.ogg, .wav)
└── data/       ← уровни, конфигурации, локализация (.json, .lua, .ini)
```

## Правила лицензий

- В каталог добавляются **только файлы с явной лицензией**, допускающей
  использование в учебном курсе.
- Лицензия и автор указываются в `LICENSE.md` каталога (или в
  `assets/README.md`).
- Не класть ассеты, скачанные без разрешения, «на время».

## Правила хранения

- Шрифт поддерживает кириллицу, если текст примеров на русском.
- Текстуры — с информацией о размере и формате.
- Звуки/музыка — с указанием битрейта, длительности и источника.
- Данные (уровни, конфиги) — текстовые, с комментариями о формате.
