# m03_templates/ex05_variadic_folds — Вариативные шаблоны и fold-выражения

> **Модуль:** `m03_templates` · **Сложность:** ★★★★☆ · **Время:** 50–70 мин
> **Запуск:** `./run.ps1 m03_templates/ex05_variadic_folds`

## Теория (кратко)

**Parameter pack** (`Ts...`) — набор произвольного числа аргументов. Раскрытие
пакета (`args...`) «разворачивает» его. **Fold-выражения** (C++17) сворачивают
пакет бинарной операцией: `(args + ...)`.

| Форма fold | Значение |
|---|---|
| `(pack op ...)` | правоассоциативное, без начального значения |
| `(... op pack)` | левоассоциативное |
| `(init op ... op pack)` | с начальным значением (для пустого пакета важно) |

## Синтаксис

```cpp
template <class... Ts>
auto sum(Ts... args) { return (args + ...); }          // pravaya svertka

template <class... Ts>
auto sum0(Ts... args) { return (0 + ... + args); }     // s nachal'nym 0

template <class... Ts>
void print_all(Ts&&... args) { ((std::cout << args << ' '), ...); }  // comma-fold

template <class... Ts>
constexpr std::size_t count = sizeof...(Ts);           // sizeof...
```

## Подводные камни

- Пустой пакет: `(args + ...)` без начального значения для пустого набора —
  ошибка; `(0 + ... + args)` даёт `0`.
- Порядок вычисления в comma-fold задаётся слева-направо (гарантирован).
- Идеальная передача пакета: `std::forward<Ts>(args)...` (с `...` снаружи).
- Рекурсивное «раскрытие» вручную (`head/tail`) сегодня заменяется folds.

## Задача

В `ex05_variadic_folds.cpp`:

1. `sum(Ts...)` через fold с начальным `0`;
2. `count_positive(Ts...)` — число положительных через fold;
3. `print_all(Ts&&...)` — печать через comma-fold;
4. `max_of(Ts...)` — максимум из числа аргументов (fold + `std::max`);
5. покажите `sizeof...(Ts)`.

## Где применяется

- Логирование и `printf`-подобные обёртки.
- `emplace`/конструкторы, передающие пачки аргументов дальше.
- Компиляция сумм/проверок по набору типов.

## Проверка

Прогон печатает суммы, количества и максимум; завершается `0`.
