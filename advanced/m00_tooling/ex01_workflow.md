# m00_tooling/ex01_workflow — Рабочий процесс: один файл, один запуск

> **Модуль:** `m00_tooling` · **Сложность:** ★☆☆☆☆ · **Время:** 20–30 мин
> **Запуск:** `./run.ps1 m00_tooling/ex01_workflow`

## Теория (кратко)

*Single-file workflow* — самый быстрый способ проверить идею на C++: один
самодостаточный `.cpp` с `int main()`, без CMake и линковки внешних библиотек.
Так проверяют гипотезы, воспроизводят баги конкурентов и пишут микро-бенчмарки.
В этом курсе так оформлено большинство заданий, чтобы фокус был на языке, а не на
сборке.

Компиляция напрямую (`g++ file.cpp -o file`) экономит время, но не отменяет
дисциплины: стандарт, уровень предупреждений и санитайзеры задаются флагами.
Скрипт `run.ps1` фиксирует эти флаги для всего курса.

## Синтаксис

```cpp
#include <print>      // std::print / std::println (C++23)

int main() {
    std::println("standard = {}", __cplusplus); // 202302L для C++23
    return 0;
}
```

Предопределённые макросы компилятора:

| Макрос | Значение |
|---|---|
| `__cplusplus` | версия стандарта: `202002L` (C++20), `202302L` (C++23) |
| `__VERSION__` | строка версии компилятора (например, `"16.2.0"`) |
| `__FILE__`, `__LINE__` | файл и строка (диагностика, логи) |

## Подводные камни

- `std::print`/`std::println` на MinGW-GCC требуют линковки `-lstdc++exp`
  (скрипт добавляет её сам). Без флага — ошибка линковки `__open_terminal`.
- `__cplusplus` отражает **запрошенный** стандарт, а не «полноту» поддержки.
- Вывод `std::print` не буферизуется как `printf`; при перенаправлении в файл
  порядок строк может отличаться от `std::cout` — не смешивайте их в одном
  выводе.

## Задача

Реализуйте в `ex01_workflow.cpp` программу, которая:

1. печатает версию стандарта (`__cplusplus`) и строку `__VERSION__`;
2. печатает числа платформы: размеры `int`, `long`, `size_t`, `double`, `void*`
   через `sizeof`;
3. демонстрирует `std::format` → строку и `std::println` в stdout;
4. возвращает `0`, если `__cplusplus >= 202302L`, иначе `1`.

## Где применяется

- Быстрая проверка гипотез и воспроизведение багов (на вендорский код кидать
  CMake-проект не нужно).
- Прототипы функций, которые потом переезжают в большой проект.
- Микро-бенчмарки и тесты поведения стандартной библиотеки.

## Проверка

Прогон `./run.ps1 m00_tooling/ex01_workflow` печатает 4–6 строк и завершается с
кодом `0`. Предупреждений компилятора нет.
