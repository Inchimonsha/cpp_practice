# m01_syntax/ex07_pointers_refs — Указатели и ссылки

> **Модуль:** `m01_syntax` · **Сложность:** ★★★☆☆ · **Время:** 50–70 мин
> **Запуск:** `./run.ps1 m01_syntax/ex07_pointers_refs`

## Теория (кратко)

**Ссылка** — это псевдоним существующего объекта: не бывает «пустой», не
переседлывается, почти всегда компактнее и безопаснее. **Указатель** — отдельное
значение с адресом: может быть `nullptr`, может меняться, поддерживает
арифметику. Правило по умолчанию: ссылка для параметров, указатель — когда
«ничего» это допустимое состояние или нужен низкий уровень.

| Инструмент | Когда |
|---|---|
| `T&` | изменить/прочитать без копии; объект точно есть |
| `const T&` | входной параметр без копии |
| `T*` | опциональное «нет объекта» (`nullptr`) |
| `T* const` | сам указатель константен |
| `const T*` | данные константны |
| member pointer | `&Class::field` / `&Class::method` |

## Синтаксис

```cpp
void scale(double& value, double k) { value *= k; }      // izmenenie
void print(const std::string& s);                        // chtenie bez kopii
bool ready(int* handle) { return handle != nullptr; }    // "mozhet ne byt'"

int arr[3]{1, 2, 3};
int* it = arr;                                           // arifmetika ukazatelej
for (; it != arr + 3; ++it) { /* ... */ }
```

Порядок `const`:

```cpp
const int* p;        // *p nel'zya menyat'
int* const q = ...;  // q nel'zya perevesti
const int* const r;  // nel'zya ni *r, ni r
```

## Подводные камни

- Возвращать ссылку/указатель на локальную переменную — висячий объект (UB).
- Разыменование `nullptr` и выход за границу массива — UB.
- Ссылка обязана быть инициализирована и не может быть «переприсвоена».
- Арифметика указателей валидна только внутри одного массива (+ один за конец).

## Задача

В `ex07_pointers_refs.cpp`:

1. напишите `scale(double&, double)` и `print(const std::string&)`;
2. напишите `optional_read(const int* p, int fallback)`, устойчивую к `nullptr`;
3. обойдите массив через указатель и вычислите сумму;
4. покажите разницу `const int*` и `int* const`;
5. используйте указатель на член класса.

## Где применяется

- `const&` для строк/векторов — стандарт передачи входных данных.
- Указатели — interop с C-API, опциональные ресурсы, структуры данных.
- Указатели на члены — рефлексия/сериализация полей, обобщённые аксессоры.

## Проверка

Прогон печатает изменение значения, сумму массива, результат чтения и `0`.
