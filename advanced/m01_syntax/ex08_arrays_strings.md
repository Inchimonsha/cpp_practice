# m01_syntax/ex08_arrays_strings — Массивы, строки, span

> **Запуск:** `./run.ps1 m01_syntax/ex08_arrays_strings`

## Теория (кратко)

Для непрерывных последовательностей есть несколько уровней абстракции: C-массив
(без размера), `std::array` (размер в типе), `std::vector` (динамический),
`std::span` (невладеющий «вид»). Для текста: `std::string` (владеет),
`std::string_view` (невладеющий взгляд), C-строки (`const char*`).

| Тип | Владеет | Размер | Когда |
|---|---|---|---|
| `T[N]` | да (стек) | фиксирован | низкий уровень / C-API |
| `std::array<T,N>` | да | фиксирован | удобнее C-массива |
| `std::span<T>` | нет | известен | параметр «непрерывный диапазон» |
| `std::string` | да | динамический | хранение/изменение текста |
| `std::string_view` | нет | известен | параметр-текст без копии |

## Синтаксис

```cpp
std::array<int, 4> a{1, 2, 3, 4};

int total(std::span<const int> values) {   // luboj nepreryvnyj diapazon
    int s = 0;
    for (int v : values) { s += v; }
    return s;
}

std::string_view first_word(std::string_view text);  // NE vladeet
```

## Подводные камни

- `std::string_view` не продлевает жизнь: `std::string_view v = std::string("x");`
  оставляет висячий вид.
- C-строка требует `'\0'`; `std::string` — нет.
- `std::array` копируется по значению целиком — передавайте по ссылке.
- `span` тоже невладеющий; следите, чтобы исходный буфер был жив.

## Задача

В `ex08_arrays_strings.cpp`:

1. посчитайте сумму `std::array` через функцию, принимающую `std::span<const int>`;
2. проверьте валидность текста по правилу (непустой, только ASCII-буквы/цифры);
3. найдите слово до первого пробела возвращая `std::string_view`;
4. соберите строку сборкой из частей и выведите длину;
5. сравните поведение C-строки и `std::string`.

## Где применяется

- `std::span` — параметр для «любого непрерывного буфера» (аудио, тайлы, verts).
- `string_view` — парсинг без аллокаций (конфиги, протоколы, токенизация).
- `std::array` — таблицы фиксированного размера (клавиши, состояния).

## Проверка

Прогон печатает сумму, результат валидации, слово и длину строки; завершается `0`.
