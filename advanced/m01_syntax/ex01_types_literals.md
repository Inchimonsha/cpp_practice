# m01_syntax/ex01_types_literals — Типы и литералы

> **Модуль:** `m01_syntax` · **Сложность:** ★★☆☆☆ · **Время:** 40–60 мин
> **Запуск:** `./run.ps1 m01_syntax/ex01_types_literals`

## Теория (кратко)

C++ — статически типизированный язык. Тип задаёт размер, диапазон и набор
операций. Начинайте с **точных** типов: фиксированная ширина (`<cstdint>`),
осознанный знак, `std::size_t` для размеров. Литерал — способ записать значение
прямо в коде с явным типом и основанием.

| Группа | Типы |
|---|---|
| Целые | `signed/unsigned char`, `short`, `int`, `long`, `long long` |
| Фиксированные | `std::int8_t … int64_t`, `std::uint8_t … uint64_t` |
| Плавающие | `float`, `double`, `long double` |
| Символьные | `char`, `char8_t`, `char16_t`, `char32_t`, `wchar_t` |
| Логический | `bool` |

## Синтаксис

```cpp
1'000'000        // цифровые разделители
0xFFu            // шестнадцатеричный, unsigned
0b1010'1111u     // двоичный
9'000'000'000LL  // long long
2.5f 3.14l       // float / long double
R"(C:\no\escape)"    // raw string: без экранирования
u8"текст"        // UTF-8 (char8_t)
```

```cpp
#include <cstdint>
std::int32_t  a = -1;         // гарантированно 32 бита
std::size_t   n = 0;          // размеры и индексы
auto          b = a + 1;      // auto выводит std::int32_t
```

Границы типов — через `std::numeric_limits<T>` (`<limits>`).

## Подводные камни

- `int`/`long` имеют **разный** размер на Windows (4 байта) и Linux (8), если не
  заданы fixed-width типы.
- Смешение знакового и беззнакового (`-1 < 1u`) даёт `true`: `-1` преобразуется в
  огромное беззнаковое.
- `char` может быть знаковым или беззнаковым — не полагайтесь на это в арифметике.
- Плавающие не равны точно: `0.1 + 0.2 != 0.3` — сравнивайте с допуском.

## Задача

В `ex01_types_literals.cpp` соберите «карту типов»:

1. напечатайте размеры и диапазоны `int`, `uint32_t`, `int64_t`, `double`;
2. создайте по одному литералу каждого вида (десятичный, hex, binary, с
   разделителями, `f`/`LL`, raw string, `u8`);
3. объявите `sizeof(char) == 1` через `static_assert`;
4. посчитайте размер UTF-8 строки в байтах;
5. не допускайте неявных сужений (проверьте строгим прогоном).

## Где применяется

- Фиксированные типы обязательны в форматах данных/сети: `uint32_t` net порядок,
  `int64_t` идентификаторы.
- `std::size_t` — размеры контейнеров; `ptrdiff_t` — разности итераторов.
- Raw-строки — регулярные выражения, пути Windows, SQL, разметка.

## Проверка

Обычный прогон печатает таблицу типов; строгий
(`-Extra '-Werror -Wconversion'`) проходит без замечаний.
