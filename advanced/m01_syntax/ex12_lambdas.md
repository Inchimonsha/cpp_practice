# m01_syntax/ex12_lambdas — Лямбды

> **Модуль:** `m01_syntax` · **Сложность:** ★★★☆☆ · **Время:** 50–70 мин
> **Запуск:** `./run.ps1 m01_syntax/ex12_lambdas`

## Теория (кратко)

Лямбда — это локальная функция-объект: `[capture](params) -> ret { body }`. Захват
определяет, что из внешней области попадёт внутрь: по значению (`=`), по ссылке
(`&`), конкретные имена, или с инициализацией (`init-capture`). Generic-лямбды
(`auto` в параметрах) превращаются в шаблоны. `mutable` разрешает менять
захваченные **копии**.

| Захват | Смысл |
|---|---|
| `[=]` | всё по значению (копии) |
| `[&]` | всё по ссылке |
| `[x, &y]` | конкретные: x — копия, y — ссылка |
| `[x = expr]` | init-capture: вычислить и захватить |
| `[this]` | захват указателя на объект |
| `mutable` | менять копии (иначе body — const) |

## Синтаксис

```cpp
auto add = [](int a, int b) { return a + b; };

int calls = 0;
auto counter = [&calls]() { return ++calls; };   // ssylka

auto twice = [n = 3 + 4]() { return n * 2; };    // init-capture

auto generic = [](auto x) { return x * x; };     // shablonnaya lambda

constexpr auto k = [](int v) constexpr { return v + 1; };  // constexpr
```

## Подводные камни

- Захват по ссылке «живёт» только пока жива переменная: лямбда, сохранённая
  дольше, даёт висячую ссылку.
- `[=]` в методе класса захватывает `this` (а не копию полей) — сюрприз при
  асинхронном вызове.
- `mutable` меняет копию, не оригинал.
- Возврат лямбды из функции, захватившей локальные по ссылке, — UB.

## Задача

В `ex12_lambdas.cpp`:

1. отсортируйте вектор по убыванию компаратором-лямбдой;
2. посчитайте число чётных через `[&]`-счётчик;
3. используйте init-capture для захвата вычисленного значения;
4. напишите generic-лямбду, работающую и с `int`, и с `double`;
5. `constexpr`-лямбду проверьте через `static_assert`.

## Где применяется

- Компараторы в `sort`/`ranges` — самый частый случай.
- Колбэки событий/кнопок (захват контекста).
- «Немедленно вызываемые» лямбды для сложной инициализации `const`.

## Проверка

Прогон печатает отсортированный вектор, счётчик и результаты; завершается `0`.
