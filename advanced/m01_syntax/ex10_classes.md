# m01_syntax/ex10_classes — Классы

> **Модуль:** `m01_syntax` · **Сложность:** ★★★☆☆ · **Время:** 60–80 мин
> **Запуск:** `./run.ps1 m01_syntax/ex10_classes`

## Теория (кратко)

Класс связывает данные и поведение и управляет доступом (`public`/`private`).
Ключевые элементы: конструкторы (в т.ч. делегирующие), деструктор, список
инициализации членов, `explicit` против неявных преобразований, `static`-члены,
`friend` и перегрузка операторов. Владение ресурсом внутри класса задаёт правило
0/3/5 (подробно — в `m02_ownership`).

| Элемент | Зачем |
|---|---|
| список инициализации | эффективная инициализация членов |
| делегирующий ctor | переиспользование логики |
| `explicit` | запрет неявного преобразования |
| `static`-член | общий для всех экземпляров |
| `friend` | доступ к приватному из «связанных» функций |
| `operator<<` | печать/логирование объекта |

## Синтаксис

```cpp
class Counter {
public:
    Counter() = default;
    explicit Counter(int start) : value_(start) { ++instances_; }
    ~Counter() { --instances_; }

    [[nodiscard]] int value() const { return value_; }
    void tick() { ++value_; }

    static int instances() { return instances_; }

    friend std::ostream& operator<<(std::ostream& os, const Counter& c);

private:
    int value_{0};
    static inline int instances_{0};
};

inline std::ostream& operator<<(std::ostream& os, const Counter& c) {
    return os << "Counter(" << c.value_ << ')';
}
```

## Подводные камни

- Без `explicit` конструктор с одним аргументом работает как неявное
  преобразование (`Counter c = 5;`).
- Члены инициализируются в порядке **объявления**, а не в порядке списка
  инициализации.
- `static inline`-член — C++17-способ иметь определение в заголовке.
- Деструктор, освобождающий ресурс, лучше не делать `virtual` без причины
  (но в иерархиях — обязателен; см. `ex11`).

## Задача

В `ex10_classes.cpp`:

1. реализуйте `Counter` с дефолтным и `explicit` конструктором;
2. добавьте `static int instances()` и деструктор, меняющий счётчик;
3. перегрузите `operator<<` как `friend` (или через геттер);
4. добавьте метод `tick(int times = 1)` с аргументом по умолчанию;
5. выведите значения и число живых экземпляров.

## Где применяется

- Классы-обёртки ресурсов (файл, сокет, текстура) — основа RAII.
- `static`-члены — реестры, счётчики, конфигурации уровня класса.
- `friend operator<<` — удобная печать в логах без раскрытия внутренних полей.

## Проверка

Прогон печатает значения счётчиков и число экземпляров; завершается `0`.
