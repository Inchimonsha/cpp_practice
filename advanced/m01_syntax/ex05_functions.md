# m01_syntax/ex05_functions — Функции

> **Модуль:** `m01_syntax` · **Сложность:** ★★★☆☆ · **Время:** 50–70 мин
> **Запуск:** `./run.ps1 m01_syntax/ex05_functions`

## Теория (кратко)

Функция — основная единица декомпозиции. У сигнатуры есть несколько
«квалификаторов»: перегрузка (по типам параметров), аргументы по умолчанию,
`noexcept` (не бросает исключений), `[[nodiscard]]` (результат важен),
`constexpr` (вычислимо на компиляции). Возвращаемый тип может выводиться
(`auto`), в т.ч. с trailing return.

## Синтаксис

```cpp
[[nodiscard]] constexpr double area(double r);          // круг
[[nodiscard]] constexpr double area(double w, double h); // прямоугольник

int clamp(int v, int lo = 0, int hi = 100);             // default args

auto add(int a, int b) -> int { return a + b; }         // trailing return

double safe_div(double a, double b) noexcept;           // ne brosaet
```

Перегрузка vs шаблон:

```cpp
void log(int);            // перегрузки — по конкретным типам
void log(double);
template <typename T> void log(const T&); // шаблон — один код для всех
```

## Подводные камни

- Неоднозначные перегрузки (`log(0)`) — компилятор выберет «лучшее», но
  несоответствие может удивить; избегайте лишних неявных преобразований.
- Аргументы по умолчанию нельзя задавать в нескольких объявлениях одной функции.
- `noexcept` — это обещание; если функция всё же бросит, вызывается
  `std::terminate`.
- Не возвращайте `const T` по значению и ссылки на локальные объекты.

## Задача

В `ex05_functions.cpp`:

1. перегрузите `area` для круга и прямоугольника;
2. добавьте `clamp(int, int lo = 0, int hi = 100)` с дефолтными аргументами;
3. напишите `constexpr double perimeter(double side)` и проверьте `static_assert`;
4. напишите `noexcept`-функцию `safe_div` и обработайте деление на ноль;
5. используйте trailing return и `[[nodiscard]]`.

## Где применяется

- `[[nodiscard]]` на функциях, возвращающих статус/результат (`parse`, `try_*`).
- `noexcept` в move-конструкторах: контейнеры выбирают перемещение только тогда.
- Перегрузки `draw(circle)`/`draw(rect)` — удобный, но осторожный приём в
  графическом API.

## Проверка

Прогон печатает площади, периметр, результат деления и `clamp`; завершается `0`.
