# m01_syntax/ex03_operators — Операторы и перегрузка

> **Модуль:** `m01_syntax` · **Сложность:** ★★★☆☆ · **Время:** 50–70 мин
> **Запуск:** `./run.ps1 m01_syntax/ex03_operators`

## Теория (кратко)

Операторы — это синтаксический сахар над функциями. Для пользовательских типов
их можно перегружать, чтобы код читался как для встроенных типов (`a + b`,
`a < b`). С появлением `operator<=>` (C++20) сравнения генерируются автоматически.

| Категория | Операторы |
|---|---|
| Арифметика | `+ - * / %` |
| Сравнение | `== != < <= > >=` |
| Логика | `&& \|\| !` (короткое замыкание) |
| Битовая | `& \| ^ ~ << >>` |
| Прочие | `?:`, `,`, `::`, `.`, `->`, `sizeof`, `<=>` |

## Синтаксис

```cpp
struct Vec2 {
    double x, y;
    Vec2 operator+(const Vec2& o) const { return {x + o.x, y + o.y}; }
    bool operator==(const Vec2& o) const = default;
    auto operator<=>(const Vec2& o) const = default;  // <, <=, >, >=
};
```

Флаги через побитовые операции:

```cpp
enum class Flags : unsigned { none = 0, hidden = 1u << 0, dirty = 1u << 1 };
auto f = Flags::hidden | Flags::dirty;   // nuzhen operator| для enum class
bool is_set = (f & Flags::dirty) == Flags::dirty;
```

## Подводные камни

- `&`/`|` для `enum class` **не работают** без перегрузки операторов.
- Путаница `&` (битовое И) и `&&` (логическое И) — частая опечатка.
- `<=>` дефолтный сравнивает поля по порядку объявления: важен порядок членов.
- `%` для плавающих не определён; для `double` используйте `std::fmod`.
- Приоритет `<<` ниже `+`: `std::cout << a + b` — это `<<(a+b)`, ок, но
  `1 << 2 + 3` = `1 << 5`.

## Где применяется

- Векторная математика в игровых движках — перегрузка `+ - * /` и `dot`.
- Битовые маски — флаги сущностей, права доступа, настройки рендера.
- `<=>` — современные контейнеры и `std::set`/`std::map` без ручных компараторов.
