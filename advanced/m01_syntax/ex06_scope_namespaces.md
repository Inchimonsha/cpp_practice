# m01_syntax/ex06_scope_namespaces — Области видимости и namespace

> **Модуль:** `m01_syntax` · **Сложность:** ★★☆☆☆ · **Время:** 40–60 мин
> **Запуск:** `./run.ps1 m01_syntax/ex06_scope_namespaces`

## Теория (кратко)

Имя видно в **области видимости** и живёт до конца **времени жизни**. `namespace`
группирует имена и предотвращает конфликты; вложенные и `inline`-namespace
удобны для версионирования API. Внутренняя связность (`static` / анонимный
namespace) делает сущность приватной для единицы трансляции.

| Механизм | Назначение |
|---|---|
| `namespace a::b {}` | вложенный namespace (C++17) |
| `using namespace x;` | «затянуть» имена (осторожно — только в `.cpp`) |
| `using x::f;` | точечно затянуть одно имя |
| анонимный `namespace {}` | внутренняя связность (как `static`) |
| `inline namespace v2 {}` | версия API по умолчанию |
| `static`-локальная | одна переменная на все вызовы функции |

## Синтаксис

```cpp
namespace game::math {
    constexpr double kGravity = 9.81;
}

using game::math::kGravity;   // точечное подключение

namespace {
    int internal_counter = 0;  // не видно за пределами TU
}
```

Поиск, зависящий от аргумента (ADL), позволяет вызывать функцию по типу
аргумента без квалификации:

```cpp
namespace geom { struct Point {}; void normalize(Point&); }
geom::Point p;
normalize(p);   // ADL найдёт geom::normalize
```

## Подводные камни

- `using namespace` в заголовке заражает всех потребителей — не делайте так.
- Порядок инициализации глобальных объектов из разных TU не определён
  («static init order fiasco»); для этого есть `constinit`/функции-локальные
  статики.
- Одноимённые `static`-функции в разных TU не конфликтуют, но и не «делятся».

## Задача

В `ex06_scope_namespaces.cpp`:

1. определите `namespace game::math` с `clamp` и константой;
2. используйте внутренний (анонимный) namespace для приватного счётчика;
3. продемонстрируйте ADL: тип в namespace + свободная функция `describe`;
4. покажите `static`-локальный счётчик вызовов;
5. подключите имя точечно через `using`, не открывая весь namespace.

## Где применяется

- Библиотеки группируют API в namespace (`sf::`, `std::`, `fmt::`).
- `inline namespace vN` — классический приём версионирования ABI.
- ADL лежит в основе `operator<<`/`swap`/`begin` и обобщённого кода.
