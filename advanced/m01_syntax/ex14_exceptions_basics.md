# m01_syntax/ex14_exceptions_basics — Исключения

> **Модуль:** `m01_syntax` · **Сложность:** ★★★☆☆ · **Время:** 50–70 мин
> **Запуск:** `./run.ps1 m01_syntax/ex14_exceptions_basics`

## Теория (кратко)

Исключение — механизм сообщить об ошибке, которую функция не может обработать
сама. `throw` запускает **раскрутку стека** (stack unwinding): вызываются
деструкторы локальных объектов, и управление передаётся ближайшему подходящему
`catch`. Ловите **по ссылке на константу** (`const std::exception&`), а не по
значению — иначе срежете производный тип и получите лишние копии.

| Средство | Назначение |
|---|---|
| `throw` | возбудить исключение |
| `try` / `catch` | перехватить и обработать |
| `catch (const std::exception&)` | стандартная база |
| пользовательский тип | доменная ошибка |
| `noexcept` | «не бросает» (иначе `std::terminate`) |
| `throw;` (без аргумента) | перебросить текущее |

## Синтаксис

```cpp
struct DivideByZero : std::runtime_error {
    DivideByZero() : std::runtime_error("division by zero") {}
};

double divide(double a, double b) {
    if (b == 0.0) { throw DivideByZero{}; }
    return a / b;
}

try {
    use(divide(1.0, 0.0));
} catch (const DivideByZero& e) {
    log(e.what());
} catch (const std::exception& e) {
    log(e.what());
}
```

## Подводные камни

- Не бросайте сырые указатели и не ловите «всё подряд» (`catch (...)` без
  необходимости) — теряете диагностику.
- Ловите по значению → slicing производного исключения.
- Деструкторы не должны бросать (иначе `terminate` во время раскрутки).
- Исключения не бесплатны на «горячем» пути; для ожидаемых ошибок используют
  `std::optional`/`std::expected` (`m05`).

## Задача

В `ex14_exceptions_basics.cpp`:

1. определите `DivideByZero` от `std::runtime_error`;
2. напишите `divide`, бросающую при нуле;
3. перехватите и выведите `what()`;
4. покажите раскрутку стека: RAII-объект, печатающий вход/выход из области;
5. добавьте функцию с `noexcept`, не бросающую исключений.

## Где применяется

- Границы модулей/слоёв: слой ловит исключение и превращает в код ошибки/лог.
- Конструкторы, которые не могут «вернуть» ошибку иначе.
- Библиотеки: `std::stoi`, `std::vector::at`, файловые операции.

## Проверка

Прогон печатает сообщение об ошибке и след раскрутки стека; завершается `0`.
