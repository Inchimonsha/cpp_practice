# m05_errors/ex01_exceptions_safety — Гарантии безопасности исключений

> **Модуль:** `m05_errors` · **Сложность:** ★★★★☆ · **Время:** 50–70 мин
> **Запуск:** `./run.ps1 m05_errors/ex01_exceptions_safety`

## Теория (кратко)

Операция, которая может бросить исключение, даёт одну из трёх **гарантий**:

| Гарантия | Обещание |
|---|---|
| **nothrow** | не бросает вообще |
| **strong** | при исключении объект остаётся в прежнем состоянии (всё или ничего) |
| **basic** | объект в валидном, но, возможно, изменённом состоянии; без утечек |

**Strong** обычно достигается приёмом **copy-and-modify-then-swap**: изменения
делаются над копией, затем готовый результат «подменяет» состояние через
`swap` (который `noexcept`).

## Синтаксис

```cpp
void add_pair_strong(int a, int b) {
    std::vector<int> next = data_;          // kopiya (mozhet brosit')
    next.push_back(a);
    next.push_back(b);                      // esli brosit -> data_ ne tronut
    data_.swap(next);                       // noexcept
}

void add_pair_basic(int a, int b) {
    data_.push_back(a);                     // uspelo
    data_.push_back(b);                     // mozhet brosit' -> chastichnyj rezul'tat
}
```

## Подводные камни

- **Basic** — это минимум: даже она требует отсутствия утечек и валидности.
- `swap` должен быть `noexcept`, иначе strong-гарантия не работает.
- Порядок операций важен: сначала всё, что может бросить, потом — `noexcept`-swap.
- Не ловите исключение «на всякий случай» и не глотайте его — искажаете гарантию.

## Задача

В `ex01_exceptions_safety.cpp`:

1. реализуйте класс-контейнер с `add_pair_strong` (copy-and-swap) и
   `add_pair_basic`;
2. смоделируйте исключение при добавлении второго элемента;
3. покажите, что после сбоя strong-версии состояние **не изменилось**;
4. покажите, что basic-версия оставляет **частично** обновлённое состояние;
5. пометьте `swap` как `noexcept`.

## Где применяется

- Контейнеры/структуры, которые должны остаться консистентными при ошибке.
- Транзакционные обновления состояния (настройки, игровые сессии).
- Любой публичный мутатор с реаллокацией/копированием внутри.

## Проверка

Прогон печатает состояние до/после сбоя для обеих гарантий; завершается `0`.
