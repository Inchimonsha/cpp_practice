# m02_ownership/ex02_special_members — Правило 0/3/5

> **Модуль:** `m02_ownership` · **Сложность:** ★★★★☆ · **Время:** 60–80 мин
> **Запуск:** `./run.ps1 m02_ownership/ex02_special_members`

## Теория (кратко)

У класса есть до пяти «специальных» функций-членов: деструктор, копирующий и
перемещающий конструкторы, копирующее и перемещающее присваивание.

- **Правило 0:** класс не управляет ресурсом напрямую (использует `vector`,
  `string`, `unique_ptr`) — тогда ничего из пяти не пишем.
- **Правило 3:** если пишешь деструктор, копирование **и** присваивание, скорее
  всего нужно написать все три.
- **Правило 5:** если добавляешь перемещение — пиши все пять.

| Функция | Роль |
|---|---|
| `~Buffer()` | освободить ресурс |
| `Buffer(const Buffer&)` | глубокое копирование |
| `operator=(const&)` | копирующее присваивание (идемпотентное) |
| `Buffer(Buffer&&)` | забрать ресурс, обнулить источник |
| `operator=(&&)` | перемещающее присваивание |

## Синтаксис

```cpp
class Buffer {
public:
    Buffer() = default;
    explicit Buffer(std::size_t n) : size_(n), data_(n ? new int[n] : nullptr) {}
    ~Buffer() { delete[] data_; }

    Buffer(const Buffer& other) : size_(other.size_), data_(...) { copy; }        // 1
    Buffer& operator=(Buffer other) { swap(other); return *this; }                // copy-swap
    Buffer(Buffer&& other) noexcept : size_(other.size_), data_(other.data_) {    // 2
        other.data_ = nullptr; other.size_ = 0;
    }
    // operator=(Buffer&&) pri copy-swap ne nuzhen: (Buffer other) prinimaet i rvalue
private:
    std::size_t size_{};
    int* data_{};
};
```

## Подводные камни

- Забыли `noexcept` на перемещении → `vector` при росте **копирует** вместо
  перемещения.
- Присваивание без самоприсваивания (`b = b`) освобождает свой же ресурс — UB;
  copy-swap решает это автоматически.
- Объявление перемещения **удаляет** копирование (и наоборот) — если нужны оба,
  объявите явно.
- «Правило 0» почти всегда лучше ручного управления: меньше кода — меньше багов.

## Задача

В `ex02_special_members.cpp`:

1. реализуйте `Buffer` над `new int[]` со всеми пятью операциями;
2. добавьте статические счётчики конструкторов/деструкторов;
3. покажите копирование и перемещение (`std::move`);
4. проверьте само-присваивание через copy-swap;
5. поместите `Buffer` в `std::vector` и покажите, что рост **перемещает**.

## Где применяется

- Собственные контейнеры/буферы (пулы, ring buffer, кадровые арены).
- Обёртки C-ресурсов (нужны move, запрет copy — см. `ex01`).
- Понимание, почему `std::vector<T>` требует корректных move-операций.
