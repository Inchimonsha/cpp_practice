# m04_stl/ex06_views_composition — Views и ленивые конвейеры

> **Модуль:** `m04_stl` · **Сложность:** ★★★★☆ · **Время:** 50–70 мин
> **Запуск:** `./run.ps1 m04_stl/ex06_views_composition`

## Теория (кратко)

**View** — лёгкий, невладеющий диапазон, который **лениво** вычисляется. Views
композируются через `|`, не создавая промежуточных контейнеров: элементы
проходят конвейер по одному, ровно столько раз, сколько нужно.

| View | Действие |
|---|---|
| `views::filter` | отбирает по предикату |
| `views::transform` | применяет функцию |
| `views::take(n)` / `drop(n)` | первые n / без первых n |
| `views::enumerate` | индекс + значение (C++23) |
| `views::iota` | последовательность чисел |
| `views::zip` | парное объединение (C++23) |

## Синтаксис

```cpp
auto pipeline = data
    | std::views::filter([](int x){ return x % 2 == 0; })
    | std::views::transform([](int x){ return x * x; })
    | std::views::take(3);

auto result = pipeline | std::ranges::to<std::vector>();  // materializaciya

for (auto [i, v] : std::views::enumerate(data)) { ... }
```

## Подводные камни

- Views **ленивы**: `transform` не выполнится, пока по диапазону не пройдут.
- Views не владеют данными: базовый контейнер должен жить.
- Нельзя вешать view на временный контейнер (`data()` временного — висячий).
- Материализуйте (`ranges::to`) до возврата/сохранения; иначе получите висячие
  ссылки.
- `views::zip` останавливается по самому короткому диапазону.

## Задача

В `ex06_views_composition.cpp`:

1. отфильтруйте чётные и возведите в квадрат, взяв первые 3 → `vector`;
2. продемонстрируйте **ленивость**: счётчик вызовов `transform` до обхода равен 0;
3. выведите пары `views::enumerate`;
4. постройте `views::iota` и `take`;
5. объедините два диапазона через `views::zip`.

## Где применяется

- Обработка данных без аллокаций промежуточных коллекций (парсинг, фильтрация).
- Конвейеры запросов (ECS-запросы, выборки сущностей).
- Ленивые последовательности поверх источников (файлы, генераторы).

## Проверка

Прогон печатает результаты конвейеров и подтверждает ленивость; завершается `0`.
