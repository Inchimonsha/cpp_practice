# Cheatsheet: th04 — ссылки, указатели, память

## Ссылка vs указатель

| | Ссылка `T&` | Указатель `T*` |
|---|---|---|
| Обязана быть инициализирована | да | нет (риск!) |
| Перепривязка | нет | да |
| «Нет значения» | невозможно | `nullptr` |
| Разыменование | автоматически | `*p`, `p->` |
| Арифметика | нет | да (осторожно) |

## Синтаксис

```cpp
int x = 5;
int& ref = x;          // ссылка
const int& cre = x;    // const-ссылка (чтение)
int* p = &x;           // указатель, `&` = взятие адреса
*p = 6;                // разыменование
p = nullptr;           // «нет значения»
if (p) { /* безопасно */ }
p->field;              // доступ к полю структуры через указатель
ref.field;             // через ссылку — как обычный объект
```

## Память: стек и куча

| | Стек | Куча |
|---|---|---|
| Освобождение | автоматически | вами (`delete`) |
| Типичные ошибки | переполнение стека | утечки, двойной `delete`, висячие указатели |

```cpp
int* p = new int(42);   // куча
delete p;               // обязательно (в курсе — только через RAII, th09)
```

## Правила курса

- По умолчанию `const T&`; `T&` — для мутации; указатель — когда может
  не быть значения или нужно хранить адрес (тогда th09).
- Ручных `new`/`delete` в курсе нет — управление памятью через RAII.
- Никогда не разыменовывайте подозрительный указатель без проверки.
- `const int* p` — данные const; `int* const p` — сам указатель const.
