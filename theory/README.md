# theory/

Теоретические темы курса. Именование: `thNN_topic_name` (пример:
`th01_cpp_project_setup`).

## Обязательный состав каждой темы

```
thNN_topic/
├── README.md      ← аннотация, цели, ссылки на связанные темы/задания/проекты
├── theory.md      ← обучающий нарратив (20 обязательных разделов)
├── examples/      ← компилируемые примеры (у каждого — свой CMakeLists при необходимости)
├── cheatsheet.md  ← шпаргалка («быстрый справочник»)
├── pitfalls.md    ← типичные ошибки и подводные камни
└── sources.md     ← источники и дополнительные материалы
```

Шаблон — в `tools/templates/theory/`.

## Структура theory.md (обязательные разделы)

1. Название
2. Цели обучения
3. Предварительные знания
4. Почему тема важна в GameDev
5. Теоретическое объяснение (от простого к сложному)
6. Синтаксис
7. Практические примеры на C++
8. Практические примеры на Lua (если применимо)
9. Применение в 2D-играх
10. Применение в песочницах
11. Взаимодействие с SFML
12. Типичные ошибки (кратко; подробно — в `pitfalls.md`)
13. Подводные камни (кратко; подробно — в `pitfalls.md`)
14. Советы по проектированию
15. Вопросы для самопроверки
16. Мини-практика
17. Связанные задания
18. Связанные проекты
19. Шпаргалка (→ `cheatsheet.md`)
20. Дополнительные материалы и источники (→ `sources.md`)

## Правила

- Не дублировать объяснения: шпаргалка и pitfalls живут в отдельных файлах и
  подключаются из `theory.md` ссылками или краткими выжимками.
- Примеры компилируются заявленным способом (C++20 + версия библиотек);
  «фрагменты кода» явно помечаются как фрагменты.
- У каждой темы есть ссылки на связанные задания (`exNN`) и проекты (`prjNN`).
