# Cheatsheet: th02 — типы, константы, операторы, условия, циклы

## Типы одним экраном

| Тип | Размер (64-бит, GCC) | Применение |
|---|---|---|
| `bool` | 1 | флаги |
| `int` | 4 | счёты, индексы, HP |
| `unsigned int` | 4 | только «нет отрицательных» |
| `float` | 4 | координаты и скорости в играх |
| `double` | 8 | точные/мировые расчёты |
| `std::size_t` | 8 | размеры контейнеров, индексы массивов |

## Объявления

```cpp
int score{0};             // {} — запрещает сужение
float speed = 5.0f;       // f-суффикс → float
constexpr int kMaxHp = 100;  // при компиляции
const int kLevel = cfg();    // один раз, но в рантайме
static int called = 0;       // живёт весь цикл программы
```

## Операторы (приоритет высокий → низкий)

- `++ -- ! unary-`
- `* / %`
- `+ -`
- `<< >>`
- `< <= > >=`
- `== !=`
- `&&`
- `||`
- `?:` (тернарный)
- `= += -= ...`

## Деление и остаток

```cpp
7 / 2 == 3      // целочисленное, дробь отбрасывается
7.0 / 2.0 == 3.5
-7 / 2 == -3    // C++20: округление к нулю
7 % 2 == 1      // остаток — чётность, циклические индексы
```

## Условия

```cpp
if (a) { } else if (b) { } else { }

switch (state) {            // только целые/enum
    case 0: /* ... */ break;
    default: break;
}

int tag = cond ? 10 : 1;    // тернарный для коротких

if (auto* e = find(); e) { }  // if-init (C++17)
```

## Циклы

```cpp
for (int i = 0; i < n; ++i) {}
while (cond) {}
do { } while (cond);          // минимум одна итерация
for (auto& m : monsters) {}   // range-for; & — изменяем элемент
break;   // выход из цикла
continue;// к следующей итерации
```

## Преобразования

```cpp
int x = static_cast<int>(f);         // явное, только так
int x = 3.7;                         // НЕЛЬЗЯ: сужение «тихо»
int x{3.7};                          // ошибка компиляции
long big = x;                        // расширение — безопасно
```

## Ловушки в двух строках

```cpp
0u - 1;                // 4294967295 (!) — модулярная арифметика unsigned
7 / 2;                 // 3, не 3.5
f == 0.6f;             // сомнительно: сравнивайте |a-b| <= eps
std::cout << x;        // печать вместо std::print (нет в GCC < 14)
```
