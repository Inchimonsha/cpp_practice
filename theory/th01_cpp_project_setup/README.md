**Модуль 0. Организация разработки.**

сборка и запуск, работа в терминале и Git, диагностика ошибок, Debug/Release,
форматирование и работа с ресурсами. Без неё невозможно выполнить ни одно
задание и ни один проект.

## Основное одной фразой

Программа: **исходник → препроцессор → компилятор → объектный файл → линкер →
исполняемый файл**. Инструменты цепочки управляются через CMake, версии кода —
через Git, качество — через предупреждения и тесты.
