# C++ и Lua: разработка 2D-игр и игровых песочниц (SFML)

Образовательный курс от начального уровня до самостоятельной разработки,
тестирования, отладки и расширения реальных 2D-игр на **C++20** и **Lua** с
использованием **SFML**.

> Язык материалов — русский. Английские термины, имена API, классов, паттернов и
> инструментов приводятся в оригинальном виде; русское пояснение добавляется при
> первом упоминании.

## Что это за курс

Курс построен как полноценная образовательная программа, а не набор
разрозненных статей. Он состоит из трёх типов разделов:

- **`theory/`** — теоретические темы с примерами, шпаргалками, разбором ошибок и
  вопросами для самопроверки.
- **`exes/`** — небольшие практические задания (exercises) для закрепления
  конкретных навыков.
- **`prjs/`** — большие пет-проекты, приближенные к реальной разработке и
  объединяющие ранее изученные концепции.

Программа разбита на модули:

| Модуль | Содержание | Разделы |
|---|---|---|
| 0 | Организация разработки | `th01` |
| 1 | Основы C++ (C++20) | `th02`–`th14` |
| 2 | Основы Lua | `th15`–`th18` |
| 3 | Математика для 2D-игр | `th19`–`th22` |
| 4 | SFML | `th23`–`th27` |
| 5 | Архитектура игры | `th28`–`th34` |
| 6 | 2D GameDev | `th35`–`th40` |
| 7 | Игровые песочницы | `th41`–`th46` |
| 8 | Профессиональная разработка | `th47`–`th51` |
| 9 | Производительность | `th52`–`th55` |
| 10 | Финальные проекты | `prj01`–`prj07` |

Полное описане тем, заданий и проектов, зависимости и этапы — в
[`ROADMAP.md`](ROADMAP.md). Словарь терминов — в [`GLOSSARY.md`](GLOSSARY.md).

Продвинутое продолжение — самостоятельный курс «Advanced C++ 2026» (C++23,
синтаксис и практика на реальных задачах) — в [`advanced/README.md`](advanced/README.md).

## Быстрый старт

### 1. Предварительные требования

- Компилятор C++20: GCC ≥ 11, Clang ≥ 14 или MSVC ≥ 19.32.
- Для сборки окна SFML на Windows нужен **MinGW-тулчейн на базе UCRT**
  (MSYS2 `ucrt64` или winlibs). Пребилт SFML собран под UCRT, поэтому
  msvcrt-тулчейн (например, bare SJLJ/SEH GCC) соберёт приложение, но оно
  упадёт при запуске из-за кросс-CRT heap-коррупции (проверено на практике).
- [CMake](https://cmake.org/) ≥ 3.20 (рекомендуется 3.25+).
- [Git](https://git-scm.com/).
- Python 3.10+ — для скриптов загрузки зависимостей и валидаторов.

Детальная инструкция по установке — в [`theory/th01_cpp_project_setup`](theory/th01_cpp_project_setup/).

### 2. Загрузка зависимостей

```bash
python tools/fetch_deps.py
```

Скрипт скачивает в `third_party/`:
- **SFML 3.1.0** (пребилт под вашу платформу и компилятор);
- **Lua 5.4.9** (исходники).

Если зависимости уже установлены в системе, скрипт можно пропустить: укажите
пути через `CMAKE_PREFIX_PATH` или переменные `SFML_ROOT` / `Lua_ROOT`.

### 3. Сборка и запуск

```bash
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build --output-on-failure
```

Запуск демо общего модуля:

```bash
./build/common/cpp_course_demo.exe        # Windows
./build/common/cpp_course_demo            # Linux / macOS
```

Запуск задания «Hello, Game Window» (решение, 5 секунд demo):

```bash
./build/exes/ex01_hello_game_window/ex01_solution.exe   # Windows
./build/exes/ex01_hello_game_window/ex01_solution       # Linux / macOS
```

Запуск пет-проекта «Arcade Game»:

```bash
./build/prjs/prj01_arcade_game/prj01_arcade.exe         # Windows
./build/prjs/prj01_arcade_game/prj01_arcade             # Linux / macOS
```

> На Windows DLL пребилта SFML и рантайм-библиотеки MinGW (`libstdc++-6.dll`,
> `libgcc_s_seh-1.dll`, `libwinpthread-1.dll`) копируются рядом с исполняемым
> файлом автоматически на POST_BUILD (см. `cmake/sfml.cmake`).

### 4. Проверки курса

```bash
python tools/validators/check_structure.py    # структура разделов
python tools/validators/check_links.py        # битые относительные ссылки
```

## Окружение

| Компонент | Версия в этом примере |
|---|---|
| ОС | Windows (win32) |
| Компилятор | MinGW-w64 UCRT GCC 16.2.0 (MSYS2 `ucrt64`, C++20) |
| CMake | 3.31 |
| Python | 3.13 |
| SFML (пребилт) | 3.1.0 `windows-gcc-14.2.0-mingw-64-bit` |
| Lua | 5.4.9 |

**Проверено:** проект собирается и тесты проходят с пребилтом SFML 3.1.0 для
GCC 14.2 (winlibs, UCRT). Оконные приложения (`ex01_solution`, `prj01_arcade`)
запускаются из `build/` без до-настройки: POST_BUILD копирует рядом с exe DLL
пребилта и рантайм MinGW-тулчейна.

> **Важно про тулчейн на Windows.** Пребилт SFML собран под UCRT. Если собрать
> SFML-приложение msvcrt-тулчейном (например, GCC 13.2 с `-static-libgcc`),
> оно *соберётся*, но *упадёт при запуске* (`0xC0000005`, heap-коррупция при
> освобождении памяти из чужой CRT). Поэтому для SFML-целей используйте
> UCRT-тулчейн (MSYS2 `ucrt64`, winlibs UCRT) — подробности и диагностика в
> [`theory/th01_cpp_project_setup`](theory/th01_cpp_project_setup/).

Если конкретная команда не выполнима в вашем окружении, проверки, которые
зависят от неё, помечены в документации соответствующим образом, а
альтернативные проверки описаны там же.

## Как работать с курсом

1. Прочитайте `ROADMAP.md` и `GLOSSARY.md`.
2. Идите по порядку модулей. Не пропускайте модуль 0 — там команды, инструменты
   и критерии качества, которые нужны во всех остальных блоках.
3. После каждой теории решайте соответствующее задание (`exes/`), затем —
   проект (`prjs/`).
4. После каждого проекта сверяйтесь с `CHECKLIST.md` и отмечайте прогресс.
5. Следите за `CHANGELOG.md`: в него записываются все изменения курса.
