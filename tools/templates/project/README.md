# Шаблон пет-проекта

Как создать проект `prjs/prjNN_name`:

1. Скопируйте каталог `tools/templates/project/` в `prjs/prjNN_name/`.
2. Заполните `brief.md`, `requirements.md`, `milestones.md`, `architecture.md`,
   `README.md`, `CHANGELOG.md`; удалите комментарии.
3. Добавьте собираемый скелет в `src/`, заголовки в `include/`, тесты в `tests/`,
   документацию в `docs/`, дизайн-заметки в `design/`.
4. Убедитесь, что проект собирается: `cmake --build build`.
5. Проверьте структуру и обновите индекс курса.

Правила больших проектов:

- разработка начинается с **vertical slice** (сквозной минимальный сценарий),
  а не с полной функциональности;
- каждый следующий проект добавляет новые инженерные задачи (см. ROADMAP.md);
- проект не должен полагаться на файлы, которых нет в репозитории.
