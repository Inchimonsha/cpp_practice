# Шаблон задания (exercise)

Как создать задание `exes/exNN_topic_name`:

1. Скопируйте каталог `tools/templates/exercise/` в `exes/exNN_topic_name/`.
2. Заполните `task.md` (26 разделов), `hints.md`, `review.md`.
3. Положите в `starter/` каркас с TODO, в `solution/` — эталон (соседнее
   решение, не единственно возможное), в `tests/` — тесты.
4. Убедитесь, что `solution/` проходит тесты из `tests/`.
5. Проверьте структуру и связи:

   ```bash
   python tools/validators/check_structure.py
   ```

6. Обновите `ROADMAP.md`, `CHECKLIST.md`, `CHANGELOG.md`.

## Правила

- Задание маленькое: 30 минут — 4 часа.
- `starter/` не содержит подсказок к решаемой проблеме — только каркас и TODO.
- Тесты проверяют решение независимо от реализации (контракт, а не детали).
- Каждое задание связано минимум с одной темой `thNN_*`.

## Поведение зависимостей

- Если заданию нужен SFML/Lua — в его `CMakeLists.txt` проверяйте наличие
  таргетов `cpp_course::sfml` / `cpp_course::lua` и пропускайте цель с
  предупреждением, если зависимость не найдена.
