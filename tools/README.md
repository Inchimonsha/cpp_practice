# tools/

Скрипты и инструменты курса.

```
tools/
├── fetch_deps.py          ← загрузка внешних зависимостей (SFML, Lua)
├── validators/
│   ├── check_structure.py ← проверка обязательной структуры разделов
│   └── check_links.py     ← проверка относительных ссылок в Markdown
├── templates/
│   ├── theory/            ← шаблон теоретической темы
│   ├── exercise/          ← шаблон задания
│   └── project/           ← шаблон пет-проекта
└── README.md              ← этот файл
```

## Загрузка зависимостей

```bash
python tools/fetch_deps.py
```

Скачивает в `third_party/`:

- **SFML 3.1.0** — пребилт под текущую платформу и компилятор
  (Linux — нативная библиотека, macOS/Windows — пребилт из GitHub releases);
- **Lua 5.4.9** — исходники с lua.org.

Параметры: `--sfml-version`, `--lua-version`, `--no-sfml`, `--no-lua`.
Подробности — в `theory/th01_cpp_project_setup` (раздел «Зависимости»).

## Валидаторы

```bash
python tools/validators/check_structure.py   # код выхода 1 при нарушениях
python tools/validators/check_links.py
```

Оба валидатора используются в CI и перед объявлением блока завершённым
(см. `AGENTS.md`, раздел 9).

## Правила

- Скрипты пишутся на Python 3.10+, без внешних зависимостей (только stdlib),
  чтобы запускались в любом окружении.
- Новый скрипт — новый README-раздел в этом файле.
- Валидаторы не должны «падать» на незаполненных разделах курса: для плановых
  (ещё не созданных) разделов выводится предупреждение, а не ошибка.
