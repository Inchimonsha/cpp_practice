# common/

Переиспользуемый код курса. Зависимостей, кроме стандартной библиотеки C++20, нет.

Содержимое:

| Путь | Назначение |
|---|---|
| `include/cpp_course/version.hpp` | Версия курса и макросы |
| `include/cpp_course/test.hpp` | Минимальный хедер-онли фреймворк для unit-тестов |
| `include/cpp_course/log.hpp` | Минимальный логгер (уровни, префикс, stderr) |
| `include/cpp_course/math/vec2.hpp` | `Vec2`: арифметика, длина, нормализация, dot product, lerp |
| `src/log.cpp` | Реализация логгера |
| `examples/demo.cpp` | Демонстрационная программа `cpp_course_demo` |
| `tests/` | Тесты модуля (исполняемый файл `common_tests`) |

## Правила

- Код добавляется в `common/` **только после ревью**; изменения фиксируются в
  `CHANGELOG.md`.
- Имена идентификаторов — английские, комментарии могут быть на русском.
- Не добавлять зависимости (внешние библиотеки) без явного решения и
  документации — модуль обязан собираться «голым» GCC/Clang/MSVC.
- Публичные интерфейсы документируются (краткие док-комментарии).

## Сборка

`common/` подключается корневым `CMakeLists.txt`. Цели:

- `cpp_course_common` — библиотека;
- `cpp_course_demo` — демо;
- `common_tests` — тесты (регистрируются в CTest как `common_tests`).
