# Milestones: prj01 — Arcade Game

## 22. План разработки по milestones

| M | Название | Результат (демонстрируется) | Зависит от блока курса |
|---|---|---|---|
| M1 | Каркас проекта | собираемый скелет: окно, пустой цикл, тесты логики проходят | этап 0 курса |
| M2 | Платформа и падение | движение платформы, предметы падают и исчезают при ловле | th23 + ex01 |
| M3 | Счёт и жизни | очки/жизни, game over, счёт на экране (текст) | th36 |
| M4 | Рекорд | сохранение/загрузка рекорда, экран результата, рестарт | th33 |
| M5 | Полировка | скорость не зависит от FPS, звук (опционально), собрание без предупреждений, тесты покрытия | th26 |

После M1–M5 достигается **vertical slice** (см. requirements.md).
Дальнейшие возможности — только после прохождения всех блоков курса.

## 23. Примерная декомпозиция задач

**M1 — Каркас**
- [ ] создать `CMakeLists.txt` проекта, подключить `common/`;
- [ ] `main.cpp` + `Game::run()` с пустым циклом;
- [ ] классы `Score`, `Aabb`, `Entity`;
- [ ] `tests/`: тесты `Score` и коллизий; регистрация в CTest.

**M2 — Платформа и падение**
- [ ] `Player` (модель) + `update(dt)`;
- [ ] спавн объектов: пул/вектор, тик по таймеру;
- [ ] движение объектов вниз с `dt`;
- [ ] удаление объектов за нижней границей;
- [ ] коллизия «платформа ↔ предмет».

**M3 — Счёт и жизни**
- [ ] переход `Score::add_points`, жизни в модели;
- [ ] «полезный/вредный» атрибут предмета;
- [ ] счёт и жизни в UI (`sf::Text`, шрифт из assets);
- [ ] game over: остановка спавна, экран результата.

**M4 — Рекорд**
- [ ] `Score::load_record/save_record` (текстовый файл);
- [ ] путь рядом с исполняемым файлом;
- [ ] вывод рекорда на экране результата;
- [ ] рестарт по `R`.

**M5 — Полировка**
- [ ] проверка независимости от FPS (30/60/120);
- [ ] звук ловли/потери (после th26);
- [ ] прохождение `ctest`, валидаторов; обновление CHANGELOG проекта.

Каждая задача — отдельный коммит `feat:`/`fix:`/`test:`/`docs:`.
