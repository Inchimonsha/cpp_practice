# Экраны: Arcade Game

## Экран 1 — Игра (Game)

- поле 800×600, тёмный фон (общий для курса: `kBackgroundColor`);
- платформа внизу, падающие предметы;
- HUD: счёт и жизни (текст слева сверху).

Переходы:
- «0 жизней» → экран результата;
- `Esc` → выход из игры.

## Экран 2 — Результат / Game Over

- текст: «Game Over», результат, рекорд;
- подсказка: «R — заново, Esc — выход».

Переходы:
- `R` → сброс модели, возврат к Game;
- `Esc` → закрытие окна.

## Поток

```
[Game] --lives=0--> [Game Over] --R--> [Game]
   ^--Esc                            ^--Esc
   +---------------------------------------> (exit)
```

Escape в обоих состояниях закрывает окно. Состояния — `GameState`,
см. architecture.md п.20.
