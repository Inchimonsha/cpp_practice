# Ассеты: Arcade Game

Правила лицензий и работы с ассетами курса — в `assets/README.md` на корне
репозитория. Краткие правила для проекта:

- **шрифт** — с открытой лицензией (OFL), кладётся в `assets/fonts/`, файл
  лицензии рядом; загрузка с проверкой ошибки;
- **звуки** (опционально, с th26) — лицензия CC0/OFL, в `assets/sounds/`;
- **текстуры** — на старте не требуются (рисунок формами SFML).

## Список на M1–M5

| Ассет | Тип | Откуда | Когда |
|---|---|---|---|
| шрифт (например, DejaVu Sans) | fonts | документирован в assets/README.md | M3 (текст на экране) |
| звук «ловля» | sounds | добавлен | M5 (опция, th26) |
| звук «потеря жизни» | sounds | добавлен | M5 (опция, th26) |

До появления шрифта в репозитории текст на экран не выводится (fake HUD-заголовок
решён через заголовок окна, решение KISS).
