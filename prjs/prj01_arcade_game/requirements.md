# Требования: prj01 — Arcade Game

## 9. Функциональные требования

1. Окно 800×600, игровой цикл с фиксированным лимитом FPS (60).
2. Управление платформой: стрелки «влево/вправо»; ввод — непрерывный.
3. Падающие объекты двух типов:
   - «полезные» (зелёные) — ловля даёт очки;
   - «вредные» (красные) — ловля отнимает жизнь.
4. Спавн объектов сверху, падение с постоянной скоростью (позже — ускорение).
5. Счёт очков и жизни (старт: 3), игра заканчивается при 0 жизни.
6. UI: счёт, жизни, экран «Game Over» с результатом и рекордом;
   рестарт по клавише `R`.
7. Рекорд сохраняется в файл `record.txt` рядом с исполняемым файлом и
   читается при запуске.
8. Звук: короткие эффекты ловли и потери жизни (опционально, начиная с th26).

## 10. Нефункциональные требования

1. C++20, сборка без предупреждений (флаги курса).
2. Логика (счёт, коллизии, спавн) не зависит от SFML и покрыта unit-тестами.
3. Скорость игры не зависит от FPS (`delta time`).
4. Никаких ручных `new`/`delete`; RAII.
5. Ресурсы загружаются с проверкой ошибок (шрифт, звук).
6. Игра завершается корректно (нет висящих потоков/циклов).
7. Архитектура: расчёт и отрисовка разделены (модель → рендер).

## 11. Ограничения

- Только C++20 + SFML 3.1.0 (+ `common/`). Других библиотек нет.
- Двумерная игра, без физического движка — коллизии определяются вручную
  (AABB).
- Хранение рекорда — простой текстовый файл (переход к структурированному
  формату — в prj02+).

## 12. MVP (minimum viable product)

Минимально играбельная версия:
окно → движение платформы → падение предметов двух типов → ловля (очки/жизни) →
game over → счёт на экране. Без звука, без рекорда, без анимаций.

## 13. Vertical slice

Сквозной сценарий «от запуска до результата»:
запуск → играю 60 секунд → набираю очки → теряю жизни → game over →
вижу результат и рекорд (сохранённый и загруженный) → жму `R` → играю снова.
Демонстрирует все подсистемы проекта в связке.

## 14. Дополнительные возможности (по мере блоков курса)

- рекорд с именем игрока (th33: структурированный формат);
- ускорение падения со временем (баланс, th40);
- увеличение сложности уровнями (th37);
- звуковые эффекты (th26);
- анимация попаданий (th38, частицы);
- пауза и меню (th29, th36).

## 15. Необходимые инструменты

- компилятор C++20, CMake ≥ 3.20, Git;
- SFML 3.1.0 (пребилт), `common/` курса.

## 16. Рекомендуемые инструменты

- VS Code + CMake Tools;
- документация SFML 3.1.0;
- clang-format.

## 17. Дополнительные инструменты
