# CHANGELOG проекта: prj01 — Arcade Game

Формат: `[дата] изменение — автор`. Технические правила курса — в `CHANGELOG.md`
на корне репозитория.

## 0.1.0 — каркас проекта (M1)

- Каркас: CMakeLists, подключение `cpp_course_common`;
- модель игры: `Score` (очки, жизни, рекорд), `Aabb`, `Entity`, `Player`,
  `FallingObject`, `GameState` — без зависимостей от SFML;
- игровой слой: `Game` (окно + цикл + рендер), движение платформы, спавн и
  падение предметов, коллизии «платформа ↔ предмет»;
- рекорд: сохранение/загрузка `record.txt` (путь от каталога исполняемого
  файла);
- тесты: `prj01_tests` (счёт, рекорд, AABB, движение) — без окна;
- документация: brief, requirements, milestones, architecture, design/, docs/.

## План: следующие milestone

- M2: спавн-пул, удаление за границей, скорость от FPS (уже частично);
- M3: вывод счёта/жизней на экране (потребуется шрифт в `assets/fonts/`);
- M4: рекорд в UI, рестарт по `R` (логика готова, ждёт UI);
- M5: полировка: независимость от FPS (проверка 30/60/120), звук (th26).
