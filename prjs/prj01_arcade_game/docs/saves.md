# Сохранения: Arcade Game

## Формат

Один файл `record.txt` рядом с исполняемым файлом, содержимое — целое число:

```
12345
```

Первый уровень: простой текстовый. Структурированный формат (JSON/бинарный),
несколько слотов — в prj02+ (тема th33).

## Стратегии

- **Загрузка** при старте (`Game::run`): если файла нет или он
  повреждён — рекорд = 0, ошибка логируется, игра запускается (не падает).
- **Сохранение** при выходе и при обновлении рекорда.
- **Атомарность** (простая): запись во временный файл, затем переименование —
  снижение риска «убитого» файла при сбое. На этом уровне optional.

## Путь

Путь строится от каталога исполняемого файла (`std::filesystem`), а не от
текущей рабочей директории — иначе запуск из IDE и из терминала дадут разные
файлы (риск п.25 architecture.md).

## Миграции

Нет (версия формата не нужна, файла может не быть вовсе).
