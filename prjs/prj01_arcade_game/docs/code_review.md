# Code Review: Arcade Game

Чек-лист ревьюера (применим и к `prj01`, и к заданиям курса).

## Слои и связи

- [ ] `include/arcade/*.hpp` и `src/score.cpp`, `src/entity.cpp`, `src/player.cpp`
      не включают анализируемых раздел SFML (grep `SFML` в чистой модели = нет);
- [ ] `Game` не лезет в модель «мимо» API (всё через публичный интерфейс);
- [ ] зависимость рендера от модели односторонняя.

## Время и движение

- [ ] `update(float dt)` принимает dt, нет глобального времени;
- [ ] скорость указана «на секунду», движение = `velocity * dt`;
- [ ] при 30/60/120 FPS поведение одинаково.

## Данные

- [ ] нет ручного `new`/`delete`; объекты по значению в контейнерах;
- [ ] `const` корректность (передача по константной ссылке);
- [ ] нет магических чисел; константы в анонимном namespace.

## Ошибки и ресурсы

- [ ] загрузка шрифта с проверкой и корректным сообщением;
- [ ] `load_record/save_record` возвращают статус, ошибки логируются;
- [ ] окно и файл-рекорд корректно закрываются при выходе.

## Тесты

- [ ] `Score` и `Aabb` покрыты; рекорд — включая повреждённый файл;
- [ ] `ctest` зелёный; smoke-тест окна под флагом, в CI — отключён.

## Git

- [ ] коммиты по задачам (feat/fix/test/docs), нет «мусорных» файлов в коммите.
