# Ассеты: стратегия (документация)

Полные правила лицензий — в `assets/README.md` в корне курса. Краткость для
проекта:

- каждый ассет — с указанием источника и лицензии (файл лицензии рядом);
- пребилты шрифта со свободной лицензией (OFL), звуки — CC0;
- ассеты не увлекать большими (загрузка в память — только используемое);
- отсутствующий ассет — это ошибка загрузки, обрабатывать её, а не «падать»;
- код не должен импортировать ассеты из `third_party/` — только из
  собственного `assets/` (или общих корневой `assets/`).

Текущий перечень — `design/assets.md`.
