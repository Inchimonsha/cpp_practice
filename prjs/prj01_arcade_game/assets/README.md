# Ассеты проекта: prj01 — Arcade Game

Каталог подключён к игре как точка монтирования ассетов (загрузка ресурсов
только из `assets/`). Общие правила лицензий курса — в
[`assets/README.md`](../../../assets/README.md) в корне репозитория.

## Содержимое

| Файл | Статус | Когда появится |
|---|---|---|
| `fonts/` (шрифт OFL) | пусто | M3, вывод текста на экран |
| `sounds/` | пусто | опционально, после th26 |
| `textures/` | не требуется | — (рисунок формами SFML) |
| `data/` | не требуется | — |

Игра не должна падать при отсутствии необязательных ассетов: их загрузка
проверяется, при отсутствии — используются программные заглушки (например,
прямоугольник вместо спрайта).

## Требование лицензий

любой добавляемый файл — с указанием источника и лицензии (файл рядом).
