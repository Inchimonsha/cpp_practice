# ex01 — Hello, Game Window

**Первое задание курса.** Открыть окно SFML, запустить игровой цикл, обработать
ввод и отследить `delta time`.

| | |
|---|---|
| Сложность | ★☆☆☆☆ |
| Время | 1–2 часа |
| Знания | th01 (настройка проекта) |
| Связанная тема | [th01 — Настройка проекта](../../theory/th01_cpp_project_setup/) |
| Связанный проект | [prj01 — Arcade Game](../../prjs/prj01_arcade_game/) |
| Требует | SFML 3 |

## Что будет в решении

- окно 800×600 с заголовком;
- игровой цикл с обработкой событий;
- движение прямоугольника стрелками (с учётом `delta time`);
- счётчик FPS в заголовке окна;
- закрытие окна по `Esc` и по кнопке окна.

## Структура

```
ex01_hello_game_window/
├── task.md            ← постановка (26 разделов)
├── starter/           ← каркас с TODO
├── solution/          ← эталонное решение
├── tests/             ← тесты (логика — без окна, smoke — опционально)
├── hints.md           ← подсказки по уровням
└── review.md          ← разбор, критерии оценки
```

Логика счётчика FPS вынесена в `shared/` — чтобы её можно было тестировать без
окна. Это первый шаг к принципу «разделение симуляции и визуализации».

## Сборка и запуск

```bash
python tools/fetch_deps.py            # один раз: SFML + Lua
cmake -S . -B build
cmake --build build --target ex01_solution
./build/exes/ex01/ex01_solution.exe

# тесты (логика, без окна)
ctest --test-dir build --output-on-failure -R ex01
```
