# ex03 — Squad Combat Simulator: постановка задачи

## 1. Название

«Squad Combat Simulator» — отряд из трёх бойцов сражается с условным врагом:
лечим, наносим урон самому слабому, печатаем отчёт о силе отряда.

## 2. Уровень сложности

★★☆☆☆ — средний: кроме циклов и условий появляются ссылки и указатели.

## 3. Примерное время выполнения

1.5–3 часа.

## 4. Цели

- закрепить функции, «чистые» контракты и области видимости (th03);
- научиться различать ссылку (обязательный объект) и указатель (может быть
  `nullptr`) для изменения данных (th04);
- понять разницу «владеет/не владеет»: отряд — это `std::vector<Fighter>`.

## 5. Какие знания закрепляются

- параметры по ссылке (`Fighter&`) vs по значению vs `const&`;
- указатели: взятие адреса, разыменование, проверка на `nullptr`;
- структуры (`struct Fighter`) и работа с ними через функции;
- `std::vector` (th05) и проходы диапазонами.

## 6. Какие навыки нарабатываются

- проектирование функций с понятными контрактами («что вернёт при пустом?»);
- аккуратная работа с указателями, возвращаемыми из функций;
- тесты на «пограничные» случаи: пустой отряд, мёртвый боец, `nullptr`.

## 8. Постановка задачи

Реализуйте библиотеку логики отряда (`shared/`) и консольную демонстрацию:

- `heal(Fighter& f, int amount)` — восстановление HP с капом по `max_hp`;
- `try_hit(Fighter* target, int damage)` — удар; `nullptr` безопасен;
- `find_weakest(std::vector<Fighter>& squad)` — указатель на живого бойца
  с наименьшим HP (или `nullptr`);
- `total_damage(const std::vector<Fighter>& squad)` — сумма урона живых.

В `main.cpp` — «раунд»: найти самого слабого и ударить его, подлечить первым
двух бойцов, вывести отчёт.

## 9. Функциональные требования

1. `heal` не воскрешает мёртвых (HP 0 остаётся 0) и не превышает `max_hp`.
2. `try_hit` уменьшает HP, но не ниже 0; возвращает жив ли боец после удара.
3. `find_weakest` игнорирует мёртвых; пустой отряд → `nullptr`.
4. `total_damage` суммирует урон только живых бойцов.
5. Демонстрация проходит цикл: пока есть слабые → слабейший теряет HP;
   2 бойца лечатся за раунд.

## 10. Нефункциональные требования

1. C++20, только стандартная библиотека.
2. Логика — в `shared/` по контракту из `squad.hpp`.
3. Каждая функция покрыта тестом (включая пограничные случаи).
4. Без предупреждений, без ручного `new/delete`, без глобальных переменных.

## 11. Ограничения

- Никаких сторонних библиотек; ввод-вывод — только в `main.cpp`.
- Функции `shared/` не должны читать/писать консоль.
- Отсутствие генератора случайных чисел: симуляция детерминирована.

## 12. Необходимые инструменты

## 14. Подсказки

- Для изменения бойца по ссылке: `void heal(Fighter& f, int amount)`.
- Указатель «или объект, или ничего» — это `Fighter*` с проверкой `!= nullptr`.
- Сравнение HP в `find_weakest`: сравнивать с «лучшим найденным на текущий
  момент», начинать с `nullptr`.

Подробные подсказки по уровням — в `hints.md`.

## 16. Критерии оценки

Полный разбор — в `review.md`. Ключевое:

- тесты на пограничные случаи (`nullptr`, пустой отряд, мёртвый боец);

## 17. Возможные расширения

- `get_damage_dealer(vector<Fighter>&)` — боец с максимальным уроном;
- раундовый отчёт: сколько HP потерял каждый боец;
- `resurrect(Fighter& f, int hp)` с условием «только для особого юнита».
