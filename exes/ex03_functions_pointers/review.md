# Разбор: ex03 — Squad Combat Simulator

## Как решать задумано

Четыре «чистые» функции логики + демонстрация. Главный урок темы —
различие между ссылкой («объект обязан быть») и указателем («объекта может
не быть»).

## Ключевые решения

### 1. Ссылка для изменения, `const&` для чтения

- `heal(Fighter& f, ...)` — изменяем переданный объект;
- `total_damage(const vector<Fighter>&)` — только читаем.

Если передать по значению — изменения потеряются; если `const&` при изменении —
не скомпилируется.

### 2. Указатель как «optional»

`find_weakest` возвращает `Fighter*`: либо адрес бойца, либо `nullptr`.
Ссылка для этого не годится — у ссылки нет «пустого» значения. Отсюда и
обязательная проверка в `describe`:

```cpp
if (weakest != nullptr) { ... } else { ... }
```

### 3. Деление мёртвых/живых

- `heal` не воскрешает: `hp == 0` → выход;
- `try_hit` опускает HP до 0, но не ниже (`std::max`);
- `find_weakest` пропускает мёртвых;
- `total_damage` учитывает только живых.

## Как выглядит эталонная схема

```
squad = vector {Mage60/100, Warrior90/100, Rogue30/60}
раунд:
  weakest = find_weakest(squad)            → &Rogue
  try_hit(weakest, 15)                      → Rogue 30→15
  heal(squad[0], 10)                        → Mage 70
  heal(squad[1], 10)                        → Warrior 100
отчёт: total_damage = 80; слабейший = Rogue (HP 15)
```

## Оценка решения (критерии)

- [ ] Все четыре функции реализованы по контракту.
- [ ] Тесты покрывают: кап лечения, не-воскрешение, `nullptr`, пустой отряд,
      все-мертвы, суммирование только живых.
- [ ] `try_hit(nullptr, ...)` безопасен.
- [ ] `-Wall -Wextra` чисто; нет ручного `new/delete`.
- [ ] Читаемость: имена по смыслу, формы `Fighter&`/`const&`/`Fighter*`
      применены осознанно.

## Частые недочёты

- `heal(Fighter f, ...)` — изменения не доходят до вызывающего;
- `find_weakest` разыменовывает `nullptr` для пустого вектора;
- «слабейший» выбирается среди всех, включая мёртвых;
- `total_damage` суммирует урон мёртвых;
- демонстрация делает вид, что слабейший «должен победить», хотя по заданию
  достаточно ударить по наименьшему HP.

## Что оцениваем как «отлично»

- в `try_hit` результат «жив ли» совпадает с тем, что реально записано в HP
  (нет двойной логики);
- `find_weakest` корректен на пустом и «все мертвы» наборе;
- решение проходит `ctest -R ex03` зелёным.
