**Закрепляет:** типы, условия, циклы, константы (th02).

|---|---|
| Сложность | ★☆☆☆☆ |
| Время | 1–2 часа |

## Что будет в решении

- консольная «боевая симуляция»: герой и монстр бьют друг друга;
- меню команд (атака / мощный удар / лечение / выход) через `switch`;
- здоровье ограничено диапазоном `[0, 100]` функциями `clamp`;
- цикл боя до победы, поражения или выхода;
- логика боя вынесена в `shared/` и покрыта unit-тестами.

## Структура

```
ex02_basics_loops/
```

## Сборка и запуск

```bash
cmake -S . -B build
cmake --build build --target ex02_solution
./build/exes/ex02/ex02_solution.exe       # интерактивная симуляция
ctest --test-dir build --output-on-failure -R ex02
```
