# ex02 — Base Defense: постановка задачи

## 1. Название

«Base Defense» — консольная боевая симуляция: герой и монстр обмениваются
ударами, пока кто-то не победит.

## 2. Уровень сложности

★☆☆☆☆ — базовое, первое задание после знакомства с типами/условиями/циклами.

## 3. Примерное время выполнения

1–2 часа (включая постановку, каркас, решение и самопроверку).

## 4. Цели

- закрепить типы, константы, условия и циклы из `th02`;
- научиться выделять «логику» в тестируемые функции (без консоли и случайности);
- впервые написать unit-тесты на собственную логику;
- изучить каркас решений курса (`shared/ + starter/ + solution/ + tests/`).

## 5. Какие знания закрепляются

- целочисленные типы и их диапазоны; деление и остаток;
- `constexpr`-константы;
- `if/else`, `switch`, циклы `while`/`do-while`;
- явные преобразования и сравнения.

## 6. Какие навыки нарабатываются

- разбиение задачи на функции с понятными контрактами;
- тестирование «чистой логики» без интерфейса;
- чтение чужого кода (starter) и завершение его по TODO.

## 8. Постановка задачи

Напишите консольную симуляцию боя:

- у героя и монстра здоровье в диапазоне `[0, 100]`, у каждого — базовый урон;
- по очереди игрок выбирает действие из меню;
- бой идёт, пока жив хотя бы один противник (или игрок не выйдет);
- в конце выводится исход («победа», «поражение», «выход из боя»).

Разрешается начинать с каркаса `starter/` (там указаны TODO).

## 9. Функциональные требования

1. Меню действий: `1 — атака`, `2 — мощный удар`, `3 — лечение`, `4 — выход`.
2. Атака наносит базовый урон; мощный удар — в 2 раза больше.
3. Лечение восстанавливает 20 HP, но не выше максимума (100).
4. Каждый ход монстр наносит герою свой урон (10).
5. Здоровье никогда не выходит за `[0, 100]`.
6. Цикл завершается при `hp` любого бойца `<= 0` или по команде «выход».

## 10. Нефункциональные требования

1. C++20, только стандартная библиотека.
2. Логика боя — в `shared/`: функции `clamp_hp`, `apply_damage`, `is_alive`,
   `calculate_hit`.
3. Каждая функция логики покрыта тестом в `tests/`.
4. Код без предупреждений (`-Wall -Wextra`), без ручного `new`/`delete`.
5. Константы (`kMaxHp`, урон лечения и т.п.) — `constexpr`.

## 11. Ограничения

- Никаких сторонних библиотек; ввод-вывод — только в `main.cpp`.
- `shared/`-функции не должны читать/писать консоль.
- Не используйте генератор случайных чисел (симуляция детерминирована).

## 12. Необходимые инструменты

- компилятор C++20 (конфигурация курса из `th01`);
- `cmake`, `ctest`.

## 13. Подготовка

1. Прочитайте `task.md` полностью.
2. Откройте `shared/include/ex02/battle.hpp` — это контракт логики.
3. Откройте `starter/main.cpp` — там TODO, которые надо реализовать.

## 14. Подсказки

- Атака и мощный удар — один `switch` с `case 1` и `case 2`.
- Баланс: мощный удар делает монстр пассивным этот ход (не обязательное правило).
- «Не больше максимума» пишется всегда одинаково: `hp = clamp_hp(hp)`.

Подробные подсказки по уровням — в `hints.md`.

## 15. Самопроверка перед сдачей

- [ ] Программа собирается без предупреждений.
- [ ] Меню реагирует на все числа 1–4 и на другие значения.
- [ ] HP не выходит за `[0, 100]` ни при уроне, ни при лечении.
- [ ] Тесты покрывают: обычный урон, мощный удар, лечение-с-капом,
      «смерть» при HP 0.
- [ ] `ctest` зелёный.

## 16. Критерии оценки

- тесты на все ветки логики;
