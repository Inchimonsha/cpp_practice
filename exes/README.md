# exes/

Практические задания (exercises) курса. Именование: `exNN_topic_name`
(пример: `ex01_hello_game_window`).

## Обязательный состав каждого задания

```
exNN_topic/
├── README.md    ← аннотация, сложность, время, связи
├── task.md      ← постановка (26 обязательных разделов)
├── starter/     ← минимальный каркас с TODO (не решение!)
├── solution/    ← эталонное решение (не единственно возможное)
├── tests/       ← тесты для проверки решения
├── hints.md     ← подсказки по уровням
└── review.md    ← разбор, критерии оценки, рефакторинг
```

Шаблон — в `tools/templates/exercise/`.

## Структура task.md (обязательные разделы)

1. Название
2. Уровень сложности
3. Примерное время выполнения
4. Цели
5. Какие знания закрепляются
6. Какие навыки нарабатываются
7. Связанные теоретические темы
8. Постановка задачи
9. Функциональные требования
10. Нефункциональные требования
11. Ограничения
12. Необходимые инструменты
13. Рекомендуемые инструменты
14. Дополнительные инструменты
15. Предварительные знания
16. Примерный план решения
17. Рекомендуемая структура файлов
18. Критерии готовности
19. Критерии проверки качества
20. Типичные ошибки
21. Подсказки по уровням
22. Дополнительные усложнения
23. Вопросы для самопроверки
24. Разбор решения (→ `review.md` или в файле)
25. Идеи для рефакторинга
26. Связь с реальной разработкой

## Правила

- Задания маленькие и точечные: закрепляют конкретный навык.
- `starter/` содержит только каркас с TODO; решение — в `solution/`.
- У задания есть тесты, которые можно запустить против `solution/`.
- Каждое задание связано минимум с одной теоретической темой.
